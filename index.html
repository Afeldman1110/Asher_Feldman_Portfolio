TeleDrive

Bluetooth remote-controlled car — dual-microcontroller embedded system

A remote-controlled car split across two STM32L4A6ZG microcontrollers — one in the handheld controller, one on the car — talking over a custom Bluetooth link.

  • I implemented the wireless Bluetooth link between the controller and the car, running a 50 Hz command protocol
  • 500 ms failsafe: if the link drops, the car stops itself instead of driving on the last command
  • Motor drive on 20 kHz PWM — above the audible range, so the motors run quiet
  • End-to-end bring-up and testing of the full system: controller input, wireless link, motor response

One Onesie

Embedded PCB system — designed from schematic in KiCad

A small wearable board I'm designing end to end. The schematic (left, Rev. 1) is built around three main parts, each picked for a job:

  • MDBT50Q Bluetooth module as the main controller and wireless link
  • NPM1300 power management IC handling battery charging and power rails off USB-C
  • BNO085 IMU for motion sensing, wired to the module over I2C with interrupt and reset lines broken out
  • Supporting details in the design: crystal load caps, I2C pull-ups, SWD debug header, RGB status LED and USB-C CC configuration
Status: ongoing design work — schematic stage shown here; this is a project in progress, not a finished product.

Pipelined RISC-V CPU

RTL design in SystemVerilog — second course in a two-course computer architecture sequence

I designed and implemented a pipelined RISC-V CPU in SystemVerilog — the full five-stage pipeline, fetch through write-back, as RTL.

  • Hazard detection and handling so instructions move through the pipeline correctly when they depend on each other
  • Branch prediction added to reduce pipeline stalls on branches
  • Wrote RISC-V assembly programs to run on the CPU and test it — the testing was the functional verification of the design

ICU — Smart Vision Counting System

Senior project for Edwards Lifesciences

My senior project: a smart vision system that counts small cloth components used to manufacture synthetic heart valves. Counting tiny, similar parts by hand is slow and error-prone — the system uses a camera to do it automatically.

  • Real client, real manufacturing constraint: the count has to be right, every time
  • Camera selection and feasibility work with the project team — evaluating machine-vision cameras against the part size and counting requirement
  • Built with the Cal Poly MEDITEC cohort, presenting interim work in February 2027 and final results in May 2027
